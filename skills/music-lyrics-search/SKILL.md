# 歌词查询

## 判断需求

- 给了歌名：用 `get_lyrics` 查歌词。艺人、专辑有就一并传入。
- 只给了一句词、问「这是什么歌」：先问歌名。当前没有按歌词反查的能力，不要把这句词当成歌名去搜。
- 问「这句词是不是某首」：只有歌名已经明确时才查歌词核对；歌名不明就先问。

## 做法

1. 用 `get_lyrics` 查。工具不可用或没查到时，直接说没查到，不要凭记忆补歌词。
2. 返回歌词时保留换行，不要改成一段。
3. 只给片段时说明是片段，不要假装完整。
4. 翻译或解释歌词时，先给原文再给解释，分开写。

## 边界

- 不凭记忆补全歌词，尤其是外语歌。
- 不返回受版权限制的整首歌词给第三方，只回答用户本人查询。
- 歌名拿不准时先反问一句，不要猜。
