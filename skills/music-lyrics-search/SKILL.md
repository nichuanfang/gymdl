# 歌词查询

## 判断需求

- 给歌名要歌词：先确认歌名和艺人，再查歌词。
- 给一句词找歌：先用这句词做关键词搜索，命中后再核对歌名和艺人。
- 问"这句词是不是某首"：先查证再回答，不确定就说不确定。

## 做法

1. 优先用现有歌词能力；没有歌词工具时，明确说"当前没有接入歌词查询"。
2. 返回歌词时保留换行，不要改成一段。
3. 只给片段时说明是片段，不要假装完整。
4. 翻译或解释歌词时，先给原文再给解释，分开写。

## 边界

- 不凭记忆补全歌词，尤其是外语歌。
- 不返回受版权限制的整首歌词给第三方，只回答用户本人查询。
- 歌名或艺人拿不准时，先反问一句确认，不要猜。
