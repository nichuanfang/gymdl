# 基于艺人/单曲的相似发现

## 步骤

1. 先确认参考对象：是某位艺人、某张专辑，还是某一首歌。
2. 提取 3–5 个可检索特征：曲风、节奏、器乐编制、语言、年代、地区。
3. 根据特征给出 3–8 个具体候选歌名，再逐首调用 `search_music` 验证。
4. 只把 `[单曲]` 结果作为推荐；合集只能作为"延伸收听"提及，且要说明是合集。

## 输出

- 一句话说明相似点，例如"都是爵士嘻哈，以采样和钢琴 loop 为主"。
- 候选写"歌名 — 艺人 — 相似点"。
- 参考对象本身已入库时，不要重复推荐同一首。

## 边界

- 不要用"类似 XX 的歌"直接当搜索词。
- 找不到足够候选时，给 2–3 首也可以，不要凑数。
