# 曲库查询

## 判断问题类型

- 是否拥有某首：先按"歌名 + 艺人"查下载记录，再用平台搜索确认是否有同曲不同版本。
- 库里有什么：按艺人、专辑、语言、年代、曲风聚合，先给结论再给少量例子。
- 歌单里有什么：只有配置了曲库或歌单工具时才能回答；没有工具就明说"当前没有接入曲库查询"。

## 查询规则

1. 优先用已有工具，不要凭记忆回答"你下载过"。
2. 歌名匹配要考虑别名、大小写、全半角、括号里的版本后缀；同一首歌的不同版本算相关，不要混成一首。
3. 查不到时明确说"没有查到"，并提示可能是记录缺失或曲库未同步，不要编造。
4. 结果多时按艺人或专辑分组，不一次性倾倒全量列表。

## 边界

- 不展示文件系统绝对路径。
- 用户问"删掉某首"时，只回答是否存在，删除操作交给用户在文件库或按钮里完成。
