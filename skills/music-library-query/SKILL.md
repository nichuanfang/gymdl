# 曲库查询

## 判断问题类型

- 是否拥有某首：用 `library_lookup` 按歌名查，有艺人就一并传入。
- 库里有哪些：用 `library_search` 按艺人或歌名片段列出，先给数量再给少量例子。
- 有多少首：用 `library_stats`。不要用它回答「有没有某一首」。
- 按语言、年代、曲风筛选：曲库没有这些字段，直接说查不了，不要编。
- 收藏同步、上一轮、入库队列：用 `favorite_status`，不要用曲库工具回答。
- 歌单里有什么：没有歌单曲目工具时明说查不了。

## 查询规则

1. 先调用工具，不要凭记忆回答「你下载过」。
2. 「有没有这首」用精确查找；「某艺人有哪些」用列表查询。
3. 查不到就说没有查到，可能是记录缺失或曲库未同步，不要编造歌名。
4. 结果多时只举工具返回的那几首，不要把截断的列表说成全部。

## 边界

- 不展示文件系统绝对路径。
- 用户问"删掉某首"时，只回答是否存在，删除操作交给用户在文件库或按钮里完成。
