# 找回遗珠

## 先预览

用户想找回听过或收藏过、但曲库里没有的歌时，调用 `rediscover_preview`。平台只能是 netease、qq、youtube，数量只能是 3、6 或 9。没说数量时用 3。

## 怎么说

- 只列出工具返回的歌名和艺人。这些歌还没入库。
- 工具说明没找满或没有结果时，把原因告诉用户：曲库已有、无法确认版本、最近看过、待上传、队列已有或暂时无法核对要分开说。
- Web 预览是临时查看，不会把歌曲记为已展示；用户想恢复“不再推荐”的歌曲时，引导他用卡片或遗珠页的“恢复推荐”。
- 用户想下载其中一首时，再用 `search_music` 查出真实单曲，让他点下载按钮。

## 边界

- 预览不会写入已展示，也不会加入下载队列。不要说已经找回或已经入库。
- 不要编造工具没返回的歌，也不要输出链接或内部编号。
