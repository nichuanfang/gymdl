# 歌单整理

## 原则

- 一个歌单只表达一个主题，不要出现"放松 + 健身 + 怀旧"这种混合标签。
- 主题优先按使用场景和情绪划分，其次按语言、年代、曲风。
- 每个歌单给一句简短描述，写清收录边界，例如"中文演唱，不含纯音乐"。

## 整理步骤

1. 先确认输入是一批歌名、一个歌单，还是用户口头描述的偏好。
2. 按主题聚类，字段用：歌名、艺人、语言、节奏、场景。
3. 同一首歌只进一个主歌单，避免重复。
4. 信息不足时，按最可能的主题归类，并标注"待确认"，不要反复追问。

## 输出格式

- 每个歌单：名称、一句话描述、曲目列表（歌名 — 艺人）。
- 单批最多 10 首，超出时先给主题和数量，再问是否展开。
- 没有实际写入歌单工具时，明确说"这是建议方案，尚未写入曲库"。

## 边界

- 不擅自删除或移动用户已有歌单。
- 写入操作只在有对应工具且用户确认后执行。
