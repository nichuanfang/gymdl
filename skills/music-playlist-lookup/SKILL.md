# 歌单说明

## 先取目录

用户问有哪些歌单、某张歌单的说明写了什么时，先调用 `playlist_catalog`。

## 怎么说

- 先说有没有同步过。没同步就说目录还没同步，不要编歌单名。
- 有说明的，只复述工具给的摘录。摘录被截断时不要补全。
- 没写说明的，直接说还没写。

## 边界

- 不能改说明，也不能创建或删除歌单。用户要改时，请他用歌单描述卡片。
- 歌单里有哪些曲目查不了。把用户已经点名的歌按主题分组时，用 `music-playlist-curation`，不要用这个技能。
