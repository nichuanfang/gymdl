# 元数据规范化

## 常见问题

- 同一艺人有多种写法：英文名、中文名、大小写、分隔符不一致。
- 专辑名带版本后缀，导致同一张专辑被拆成多张。
- 流派缺失或一律写成"流行"，无法用于分类。
- 年份被写成当前年份，失去原始发行信息。

## 规范化规则

1. 艺人：保留原语言主名，多个艺人统一用 ` / ` 分隔，去掉多余空格。
2. 专辑：去掉 `(Deluxe)`、`[Remastered]` 这类版本标记前先确认是否是同一张，不要直接合并。
3. 流派：从具体到宽泛，最多两级，例如 `Jazz / Fusion`；不要用"流行"兜底所有歌。
4. 年份：保留原始发行年；确实未知时留空，不要填当前年份。
5. 纯音乐：没有歌词且以器乐为主时标 `Instrumental`，不要标成语言类。

## 输出格式

- 先列问题，再给"原值 → 建议值"的对照。
- 批量处理时最多列 10 条，其余给规则说明。

## 边界

- 不直接改用户文件，只给建议值。
- 不确定的字段标"待确认"，不要编造。
